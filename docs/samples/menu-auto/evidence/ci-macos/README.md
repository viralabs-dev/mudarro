Failure: Master PTY EOF returned zero on macOS and was treated as an input timeout, leaving the menu running. Timeout cleanup closed the slave while a goroutine called File.Fd, causing a race. A subsequent queued-stdin test sliced a negative syscall.Read length, causing panic. Signal-observer cleanup also exposed a race in repeated local verification.

Corrective fix: platform-specific select readiness with a 100ms deadline, VMIN=1/VTIME=0, one-byte read, readable zero -> EOF, preserve pending escape bytes on timeout/EINTR/EAGAIN. Refuse descriptors outside select's bounded set. EOF tests use a subprocess killed and joined on timeout; signal observer is cancelled/joined before closing the slave. Child-stdin test checks errors/length before slicing and models a child delivering newline after canonical restoration.
